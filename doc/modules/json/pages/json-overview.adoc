= JSON

http://json.org/[JSON] is a textual data format that encodes booleans, numbers, and strings, as well as http://en.wikipedia.org/wiki/Array_data_structure[arrays] and http://en.wikipedia.org/wiki/Associative_array[associative arrays] (called JSON objects).


NOTE: Trial.Protocol supports http://tools.ietf.org/html/rfc7159[RFC 7159]. No http://json5.org/[JSON extensions] are supported.

== Overview

Trial.Protocol provides the following classes for JSON parsing and generation.
